# iron_blade_engine
 a 2d game engine with focus on android and arm linux platforms
 
 este projeto foca em ser uma plataforma de prototipagem de jogos focada principalmente no android mas que também funcionará bem em computadores. E embora seja principalmente para prototipagem nada impede que lançamentos finais usem essa engine. o projeto usaŕa como linguangens rust para desenvolver o motor e lua como linguagem de script talves seja necessario um pouco de kotlin tambem para fazer a interface no android mas vou manter ao minimo possivel.
 a engine seguira um disign o mais minimalista possivel focado em jogos 2d e numa abordagem de desemvolvimento rápida.
